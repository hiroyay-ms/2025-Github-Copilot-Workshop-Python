# Stage 7: 通知機能 手動テストガイド

## テスト準備

1. Flaskアプリケーションが起動していることを確認
   ```bash
   python app.py
   ```

2. ブラウザで http://localhost:5000 にアクセス

## テスト項目

### 1. 通知許可リクエスト

**手順:**
1. ページを読み込む
2. ブラウザに通知許可のダイアログが表示される

**期待結果:**
- 通知許可のダイアログが表示される
- コンソールに通知許可の状態がログ出力される

**確認方法:**
- ブラウザの開発者ツール（F12）を開く
- コンソールタブを確認
- 「通知が許可されました」または「通知が拒否されました」が表示される

### 2. 通知音の再生

**手順:**
1. 「開始」ボタンをクリック（テスト用に1分に設定することを推奨）
2. タイマーが完了するまで待機（または強制的に完了をトリガー）

**期待結果:**
- タイマー完了時にビープ音が再生される
- 音声ファイル（notification.wav）が正常に再生される

**確認方法:**
- スピーカー/ヘッドフォンの音量を確認
- 音が鳴ることを確認

### 3. ブラウザ通知の表示

**前提条件:**
- 通知許可が「許可」されていること

**手順:**
1. 「開始」ボタンをクリック
2. タイマーが完了するまで待機

**期待結果:**
- 作業セッション完了時：「作業セッション完了！休憩しましょう」が表示される
- 休憩セッション完了時：「休憩終了！次の作業を始めましょう」が表示される
- 通知のタイトルは「ポモドーロタイマー」

**確認方法:**
- デスクトップ右上または下部に通知が表示される
- 通知をクリックするとブラウザウィンドウがフォーカスされる
- 5秒後に通知が自動的に閉じる

### 4. 通知許可が拒否された場合

**手順:**
1. ブラウザの設定で通知を拒否
2. ページをリロード
3. 「開始」ボタンをクリック
4. タイマーが完了するまで待機

**期待結果:**
- 通知は表示されないが、音声は再生される（エラーは発生しない）
- コンソールに「Notification permission not granted」が表示される

### 5. Notification APIが利用できないブラウザ

**手順:**
1. 古いブラウザまたはNotification APIをサポートしていない環境でテスト

**期待結果:**
- コンソールに「This browser does not support notifications」が表示される
- アプリケーションは正常に動作し続ける（音声のみ再生）

## トラブルシューティング

### 音が鳴らない場合

1. ブラウザの音声が許可されているか確認
   - Chrome: サイトの設定 → サウンド → 許可
   
2. スピーカー/ヘッドフォンの音量を確認

3. ブラウザコンソールでエラーメッセージを確認

4. 手動で音声テスト:
   ```javascript
   const audio = new Audio('/static/assets/notification.wav');
   audio.play();
   ```

### 通知が表示されない場合

1. ブラウザの通知設定を確認
   - Chrome: 設定 → プライバシーとセキュリティ → サイトの設定 → 通知

2. OSの通知設定を確認
   - Windows: 設定 → システム → 通知
   - macOS: システム設定 → 通知

3. ブラウザコンソールで通知許可状態を確認:
   ```javascript
   console.log(Notification.permission);
   ```

## 成功基準

- ✅ アプリケーション起動時に通知許可がリクエストされる
- ✅ タイマー完了時に音声が再生される
- ✅ 通知許可がある場合、ブラウザ通知が表示される
- ✅ 通知メッセージが適切（作業/休憩で異なる）
- ✅ 通知が拒否されてもアプリケーションは正常動作
- ✅ エラーハンドリングが適切に機能
