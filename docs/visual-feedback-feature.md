# 視覚的フィードバック機能（パターンA）

## 概要
ポモドーロタイマーの集中時間中に視覚的な没入感を高める新機能を実装しました。

## 実装した機能

### 1. 円形プログレスバーの色変化アニメーション
- **動作**: タイマーの進行に応じてプログレスバーの色が滑らかに変化
- **色のグラデーション**:
  - 0-50%: 青 (#5B68E8) → 黄 (#FFC107)
  - 50-100%: 黄 (#FFC107) → 赤 (#F44336)
- **実装ファイル**: `static/js/ui-controller.js`
- **メソッド**: `updateProgressColorGradient()`, `interpolateColor()`

### 2. 背景エフェクト
集中モード（作業セッション）中のみ表示される視覚的エフェクト

#### パーティクルアニメーション
- 20個の浮遊パーティクルが下から上へ流れる
- ランダムな位置と遅延時間で自然な動き
- 半透明の青色で没入感を演出

#### 波紋エフェクト
- 3つの同心円が中心から広がるアニメーション
- 繰り返し再生で連続的な視覚効果
- 6秒間隔で展開

### 3. 制御ロジック
- **開始時**: 作業セッションの場合のみ背景エフェクト開始
- **停止/リセット時**: 背景エフェクトを即座に停止
- **完了時**: 背景エフェクトを停止し、通知を表示

## 技術的詳細

### 色補間アルゴリズム
RGB値を線形補間して滑らかな色遷移を実現:
```javascript
interpolateColor(color1, color2, ratio)
```

### パフォーマンス最適化
- CSS3アニメーションを使用（GPU加速）
- `pointer-events: none` でクリックイベントを透過
- `z-index: -1` で背景レイヤーに配置
- フェードイン/フェードアウトで滑らかな表示/非表示

### アクセシビリティ対応
```css
@media (prefers-reduced-motion: reduce)
```
モーションを減らす設定に対応し、アニメーションを最小化

## 使用方法

### 基本的な使い方
1. 「開始」ボタンをクリックしてタイマーを起動
2. 作業セッション中は背景エフェクトが自動的に表示
3. プログレスバーの色が時間経過とともに変化

### 期待される効果
- 視覚的フィードバックによる集中力の向上
- 残り時間の直感的な把握
- 没入感のある作業環境
